# Ingestion pipeline and lifecycle automation

## Mandatory adapter contract

- Every adapter in `MANDATORY_ADAPTERS` (`scripts/ingest/run.ts`, 18 mandatory sources: `artificial-analysis`, `aikido`, `cwe-bench`, `deepswe`, `epoch`, `frontier-harness`, `lmarena`, `tbench`, `harness-leaderboard`, `livebench`, `vals`, `vulcanbench`, `designarena`, `writing-feeds`, `scale-seal`, `surge`, `weirdml`, `pricing`) is mandatory and uses relative imports (`../../src/...`) for Bun 1.4.x and Node.js 26 LTS parity.
- `scripts/ingest/sources/frontier-harness.ts` fetches FrontierHarness Eval v1.1 (`https://frontierharness.org/api/live?since=0` + `/api/summary`, upstream 22 harnesses × 5 open control models × 62 tasks × 4 attempts = 27,280 runs), enforces distinct non-empty `(subset, taskName)` identities, unique `finished_fields` column names, unique `live.outcomes` codes, hard minimum subset task floors (`tb21 >= 45`, `tb4 >= 17`), explicit integer `attempts >= 2`, and raw numeric `0 | 1` `lookup` values on every row, deduplicates identical replay variants before counting unique conflicts so replays never cross rejection thresholds, marks conflicting duplicates corrupted to reject affected slices, requires complete `(model, task)` cell coverage (`cellMap.size >= totalExpectedTasks * modelCountInSlice`) and `>= 90%` run completion per slice, excludes `"infra"` outcomes, scores reward-hacking `lookup > 0` passes as failures, averages non-negative priced attempts (`parseNonNegative`) within each `(model, task)` cell first before equal-task averaging (`costCount > 0` per cell and `subCostMean > 0`), and emits per-benchmark and overall `passRate`, `taskClusteredCiPct` (`ciIsUpperBound: false` when measured), and per-benchmark-tracked exact unbiased `pass^3`.
- `scripts/ingest/sources/harness-leaderboard.ts` fetches the Apache-2.0 Coding-Agent Harness Leaderboard (`https://joelniklaus-harness-leaderboard.hf.space/`, inline `#hlb-data` JSON), validates contributing single-effort slices at full source precision (integer `n_scored >= authN`, exact asymmetric single-effort `[ciLower, ciUpper]`, separate lower/upper delta propagation on averages), requires boolean `complete === true`, unrounded `macro` agreeing within `0.15` pp of validated constituents and rollup rates agreeing within `0.15` pp of validated contributors, authoritative `config.benchmarks[bmId].subset_sizes.full`, exact `n_tasks === n_tasks_expected === effortMultiplier * authUniqueN`, reconciled `row.n_scored === sum(bm.n_scored)`, `>= 8` complete harnesses per slice, row+constituent `n_tasks3` and Fréchet-Hoeffding `p3 >= max(0, 3p - 200) - 0.15` feasibility before publishing `passAll3Rate` (clearing constituent `passAll3Rate` when row eligibility fails), and explicit `ciIsUpperBound: boolean` on every benchmark. `compileDomainsFromSources` (`scripts/ingest/run.ts`) projects each into a separate instrument in `harnessLeaderboard` via `mergeControlledHarnessSuites`, and BOTH live `refreshMandatorySource` and `readSourceCacheStrict` (`scripts/ingest/cache.ts`) enforce exact source-specific benchmark rosters via `validateHarnessSourceBenchmarks`.
- `scripts/ingest/sources/cwe-bench.ts` ingests the registered 250-task (`100` public + `150` held-out exact split, every row `tasks === 250`) CWE-bench v2 dataset (`data-v2.js` + required nonempty unique HTML table `tds[1]` revision-qualified model names & harness, stable chart-key `sourceRowId` for caching & disqualification, `ci95`, measured cost, `<time datetime>` / `dateModified` publication date, and unambiguous v2-only protocol effort marking the partition degraded if missing) while `aikido.ts` ingests detection scores; `weirdml.ts` emits `weirdml_v3` into `harnesses` with explicit `rawHarness`; `epoch.ts` reads nine score CSVs and supersession notices in `benchmark_metadata.csv` from `benchmark_data.zip` via built-in `node:zlib` PKZIP extraction, strips inference-host suffixes on either side of effort suffixes, checks `isRegisteredModelExact` before effort stripping, overrides strictly `_unknown` with verified effort column while quarantining effort contradictions, and includes resolved effort in ID-less row keys; `lmarena.ts` keeps 1 non-overlapping split per crowd arena requiring explicit published `ciLower`/`ciUpper` bounds containing the rating within `0.01`; `designarena.ts` keeps `designarena_website`, strictly validating `btStdErr` and integer counts (`parseStrictNonNegativeInt`); adapters compare every normalized `RawObservation` field strictly (`observationsMatchExact`) order-independently and emit conflicting `sourceRowId`s in `disqualifiedSourceRowIdsByBenchmark` so degraded cache retention never restores quarantined rows. `deepswe.ts` leaves August 12 `deepseek-v4-pro` attributed to the retired April checkpoint, while `writing-feeds.ts` attributes verified August 20 `DeepSeek V4 Pro (high)` to `deepseek-v4-pro-0813` while preserving `evalDate: null` and parsing latest changelog `publishedDate`. External-harness overrides (`rawHarness !== null`) are excluded on all non-Harnesses domains inside `extractAcceptedCellsFromSources`, and BOTH live `refreshMandatorySource` and `readSourceCacheStrict` enforce strict `sourceId === adapter.id` ownership per cache file.
- `scripts/ingest/cache.ts` loads existing caches strictly via `readSourceCacheStrict`, merges observation partitions, pricing, and `harnessLeaderboard` uniformly through rejection (`> 10%`), 3-day `.shrink-state.json` shrink confirmation (`__harness_leaderboard__` sub-feed + row/slice drop detection), and upstream timestamp rollback/staleness gates (`compareIsoInstants < 0` or `> 14d` old retains healthy cache as degraded), strips `disqualifiedSourceRowIdsByBenchmark` from degraded retained partitions, and excludes live `conflictingPricingApiSkus`/`conflictingPricingModelSlugs` from cached price fallback.
- Validate upstream versions, required columns, and per-row metadata joins inside adapters before replacing healthy partitions: `vals.ts` requires `typeof metadata.version === "string"`, unconditionally parses `BenchmarkViewLoader` + `refusal_fallback` (both `JSON.parse` and Rolldown inline object literals without `eval`), excludes gated `-range`/`daybreak` variants, rejects contradictory effort labels, and preserves `seRaw`; `tbench.ts` emits `tbench_4_1` into domain `"harnesses"`, enforces `MIN_TBENCH_4_1_TRIALS = 330` (66 tasks x 5 repeats), requires explicit non-null `reasoning_effort`, rejects malformed metadata and token-count conflicts, and divides run token totals by `n_trials`; `livebench.ts` validates `cost.csv` headers and divides category token totals by `nq_*`; `artificial-analysis.ts` parses `/leaderboards/models`, `/evaluations/aa-briefcase`, `/evaluations/gdpval-aa`, `/evaluations/code2video-aa`, and `/agents/coding-agents` into unified identity records with strict effort provenance; `scale-seal.ts` extracts exact `confidenceInterval_upper` half-widths; `http.ts` retries transient 5xx/timeout errors once cleanly.
- Concatenate Next.js Flight chunks verbatim via an O(n) linear scanner and parse dates strictly in UTC via `parseIsoDate` (`scripts/ingest/http.ts`). Use `fetchArrayBufferWithSafeAuth` for credential-safe multi-hop HTTPS redirects.

- `surge.ts` isolates the named leaderboard from other tables on each page. Keep Hemingway expert Elo with the published 95% bounds and withhold ambiguous DeepSeek checkpoints. AA bounded scores use the registered evaluation protocol and reconcile overlapping row IDs. Code2Video task cost uses uncached token totals across the pinned 114 briefs and carries estimated-cost provenance.

## Immutable epochs, cryptographic manifest, and full-recompute validation

- `scripts/ingest/lock.ts` holds an OS-kernel cross-process publish lock via `node:sqlite` (`DatabaseSync` `BEGIN EXCLUSIVE` on `data/epochs/.publish.lock.db` with `busy_timeout = 0` and `journal_mode = DELETE`, identical across Bun 1.4.x and Node.js 26 LTS) plus `AsyncLocalStorage` re-entrancy.
- `scripts/ingest/generation.ts`, `scripts/ingest/cache.ts`, `scripts/ingest/sync.ts`, and `src/lib/data.ts` implement WAL-journaled generation staging, `"r+"` `fsyncFile`, POSIX `fsyncDir`, idempotent copy-replace rollback, and cold-load coalescing.
- `scripts/ingest/run.ts` recomputes `harnessLeaderboard` independently via `recomputeHarnessLeaderboard` + `HarnessLeaderboardSnapshotSchema.parse` inside `compileDomainsFromSources` (never blindly copying cached frontier annotations), validates historical MAJOR epoch archives via `validateFrozenMajorEpochSnapshot` (checking archived `rm.coverageFloor`, complete `(regime, provider, harnessFilter)` roster across valid regimes up-front, deterministic frontier/pruned metrics, `::all` `paretoProb`/`imputationSensitive` config reconciliation, slice-specific `imputationSensitive` and non-imputed `paretoProb`, `verdicts`, and joint-link Woodbury REML parity), refuses to trust unpinned on-disk MAJOR archives, refuses to freeze a new MAJOR regime whose active benchmarks all already hit hard lifecycle triggers, preflights all pins/chains/digests before any `fs.link`, and pins SHA-256 hashes in `data/epochs/manifest.json`.
- `scripts/ingest/audit-lifecycle.ts` keys prior audits by `benchmarkId::harnessRegime::benchmarkVersion`, recovers WALs, validates `lifecycleOverride` before mutating disk, and compares instants via nanosecond `compareIsoInstants`.
- `scripts/ingest/validate-snapshot.ts` enforces strict `HarnessLeaderboardSnapshotSchema` (`slices.length >= 1`, `slices[0].sliceId === "_all"`, unique IDs, CI bounds, `passAll3Rate <= passRate`, valid `dominatedById`, upstream timestamp freshness), independent `recomputeHarnessLeaderboard` parity, `regimeMeta.costSource`/`measuredCostBenchmarkIds`/`priorMean`/`tauModelSq` parity, weighted-zero Rasch delta gauge (`|sum(w*delta)| <= 1e-3`), verified API pricing and `shrinkageFactor >= 0.50` on every eligible config, strict fail-closed `computeConfigPosterior` (`shrinkageFactor`, `theta`, `se`, `samplingSe`, `residualSe`) verification, manifest-pinned archive validation (including all-config REML `priorMean`/`tauModelSq` recomputation), full deterministic raw-to-release recompute parity, and `data/lifecycle.prev.json` verification.
- `.github/workflows/ci.yml` sets `STRICT_FRESHNESS: "1"`, validates multi-commit batch pushes step-by-step using each commit's own `git archive "$COMMIT"` tree, and enforces append-only `data/epochs/manifest.json` and nanosecond chronology.
