## Reasoning settings

Vals publishes a compact chart preview and a full, versioned benchmark file. The latter records the settings used to produce each score. The unsuffixed Claude Fable 5.2 entry on Code Migration ran at high effort even though the evaluator's current model registry lists max. ProChoice reads the run's recorded reasoning or compute effort, validates an explicit model-key or display-label setting, and retains reported thinking-on or thinking-off modes. It withholds a run when no setting can be resolved, when fields disagree, or when the provider reports an unsupported numerical effort. The headline row supplies the identity join for Excel; the score, SE, cost and configuration come from the Scratch row with the same source model ID. The evaluator's refusal ledger excludes fallback answers. [Code Migration release](https://www.vals.ai/benchmarks/code-migration-v1-1) · [Excel release](https://www.vals.ai/benchmarks/emb-v1-1)
