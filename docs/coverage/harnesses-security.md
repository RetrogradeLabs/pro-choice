## Defensive security

The current defensive Cyber composite combines repair verification on CWE-bench v2 and defect detection on Aikido. A valid patch must repair the defect and preserve legitimate behavior. Aikido’s F1 includes false positives as well as missed defects. Their published protocols describe different work and different source panels. Private tasks prevent an item-level disjointness guarantee. The mixed competition measure is retired from the current release. [CWE-bench v2](https://cwe-bench.com/) · [Aikido Arena](https://www.aikido.dev/aikido-arena)
